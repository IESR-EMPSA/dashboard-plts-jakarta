## Completed milestone 1 — Data preparation

Scripts use the existing Node runtime, with no new application dependencies. Data-only types, explicit administrative/type crosswalks, deterministic JSON and normalized boundaries are implemented. Raw sources remain immutable. See DATA_PIPELINE.md for commands and schemas.

Acceptance achieved: 1,747,249 all analyzed; 1,470,399 eligible; 1,466,275 with PVOUT; 4,124 missing; 18,627.76699292319 MWp and 25,117.47645231979 covered GWh/year. Counts match exactly, tolerance is 0.000001, all joins are one-to-one, and Seribu Utara annual GWh remains null. Negative tests reject malformed numerics/CSV, unknown/duplicate joins, incorrect counts/totals, unexpected schemas/CRS and ambiguous aliases. Generated bytes are deterministic and freshness-checked.
